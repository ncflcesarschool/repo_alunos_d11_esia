# Apoio textual

[Guia passo a passo de AV1.1, AV1.2, AV1.3 e AV2](guia-atividades-aula4.html): percurso de 60 minutos para o início da aula 4, com os dados das atividades, instruções de preenchimento, exemplos, modelos copiáveis e critérios de avaliação. Abre localmente e permite imprimir todo o conteúdo.

[resultado-textual.md](resultado-textual.md) registra uma execução real das verificações do material inicial, com comando, ambiente e saída observada. Pode ser usado sem Python local; nesse caso, declare que analisou uma transcrição.

[saidas-simuladas.md](saidas-simuladas.md) contém seis respostas didáticas redigidas para B2, com instruções A/B. Simulações e transcrições de execução têm origens diferentes e devem ser identificadas nos registros da atividade.

[artefatos-para-revisao.md](artefatos-para-revisao.md) reúne documentação, teste e nota de revisão candidatos para B4. O [cenário organizacional](cenario-organizacional.md) fornece os fatos fictícios para a política de B5 e o parecer de maturidade de B6.
